Blueprints: Image Denoiser (example)

A small Python package that removes noise from 2D images with a total-variation method, for a lab that scans samples on a benchtop microscope. This is a made-up example that shows what a finished front page looks like. One blueprint per component. Start at the top and read down.

Core components

1. Theory

settled

The noise model, the total-variation objective, and the gradient-descent iteration that minimizes it, with the one equation each step uses.

2. Software Architecture

for review

One Denoiser object holds the parameters and computes denoise; images are NumPy arrays; nothing is saved to disk by the package itself.

3. Hardware Mapping

not needed

Not needed: the images are under 10 megapixels and the iteration runs in under a second on any laptop CPU.

4. User API

drafting

Three scripts: denoise one image, denoise a folder, and tune the strength on an image with a known clean version. Four public names.

Optional components

5. Pre and Post Processing

not started

Reading the microscope's TIFF stacks, converting 16-bit counts to floats, and writing results back as TIFF.

6. Testing and Verification

not started

Match the lab's MATLAB script number for number on three saved images; one test per public name; a test that the objective never increases.

Documentation and Release were not chosen: the package is for one lab and ships as a folder. Decisions and rejected alternatives are recorded, with dates, in decisions.md.
